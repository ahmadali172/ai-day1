Local LLM Chat



A simple Node.js script that chats with a local AI model using Ollama.



\## Requirements

\- Node.js

\- Ollama with the llama3.2 model (`ollama pull llama3.2`)



\## Run it

&#x20;   node chat.mjs



\## What I learned

\- Running LLMs locally with no API key

\- Calling a local model from Node.js
